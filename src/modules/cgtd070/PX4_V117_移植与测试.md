# PX4 v1.17 移植与测试

## 覆盖模块和消息

把新版目录复制到 `src/modules/cgtd070` 后，必须同时更新PX4根目录的
消息定义，因为 `Cgtd070Status.msg` 已精简为四个字段：

```sh
cd ~/PX4-Autopilot-1.17.0
cp src/modules/cgtd070/msg/Cgtd070Status.msg msg/Cgtd070Status.msg
grep -n 'Cgtd070Status.msg' msg/CMakeLists.txt
make cuav_fmu-v6x_cgtd070
```

SITL测试目标使用：

```sh
make px4_sitl_cgtd070 none
```

## 空载测试

```text
cgtd070 start -d /dev/ttyS3
cgtd070 status
```

无吊舱时RX为0正常；TX应约25 Hz增长，所有硬I/O错误应为0。即使姿态、
GPS、电池或Home主题没有数据，44字节帧也会持续发送，相应遥测字节为0。

## 虚拟反馈测试

向虚拟串口写入厂家64字节示例帧，再执行：

```text
listener cgtd070_status 1
```

预期：

```text
los_az_rate: 4.75
los_el_rate: -7.96
gimbal_roll: 36.14
gimbal_pitch: 15.22
```

其中 `gimbal_roll` 是按需求指定的名称，实际承载协议中的吊舱方位/框架角。
